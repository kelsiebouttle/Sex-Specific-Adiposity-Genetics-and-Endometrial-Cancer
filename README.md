# Sex-Specific-Adiposity-Genetics-and-Endometrial-Cancer
This repository contains the analysis code for Bouttle et al. (2026).

Preprint: https://www.medrxiv.org/content/10.64898/2026.03.29.26349665v1

Scripts implemented include LD score regression, sex-stratified common factor GWAS, residual matrix analysis, progressive model fitting, sex-difference comparisons, heritability estimation, MiXeR cross-trait analysis, MAGMA gene-based testing, LDpred2 polygenic score construction, PHESANT phenome-wide association, cross-trait association (CPASSOC), colocalisation (COLOC), GWAS-by-subtraction, mediation analysis, and fine-mapping (SuSiEx).

# Input GWAS

Endometrial cancer: 17,278 cases, 289,180 controls (N = 306,458)

Six adiposity traits were analysed sex-stratified, alongside endometrial cancer as the outcome trait. All GWAS were conducted in individuals of European ancestry.

# Female adiposity GWAS
- BMI: N = 434,794 (PMID: 30239722)
- Waist-to-hip ratio: N = 381,152 (PMID: 30239722)
- Body fat percentage: N = 154,337 (PMID: 37867527)
- Visceral adipose tissue: N = 20,038 (PMID: 35773277)
- Abdominal subcutaneous adipose tissue: N = 20,038 (PMID: 35773277)
- Gluteofemoral adipose tissue: N = 20,038 (PMID: 35773277)
