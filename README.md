# Sex-Specific-Adiposity-Genetics-and-Endometrial-Cancer
This repository contains the analysis code for Bouttle et al. (2026). Scripts implemented include sex-stratified common factor GWAS,sex-difference comparisons, MiXeR analysis, MAGMA, polygenic score construction, phenome-wide association, CPASSOC, colocalisation, GWAS-by-subtraction, mediation analysis, and fine-mapping.
